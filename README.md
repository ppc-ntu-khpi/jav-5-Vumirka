## 🌸 Опис проєкту

> У рамках практичної роботи була створена ієрархія класів для моделювання
> структури компанії та згенерована веб-документація за стандартом **Javadoc**.

Проєкт містить пакет `domain`, який моделює структуру співробітників:

<details>
<summary>🌷 Класи пакету domain</summary>

<br>

- `Employee` — базовий клас з основними даними про працівника (ім'я, посада, рівень, відділ, ID)
- `Manager` — керівник, який управляє масивом підлеглих (`Employee[]`)
- `Artist` — творчий фахівець із переліком навичок (`String[]`)
- `Editor` — редактор (нащадок `Artist`) з ознакою типу редагування (електронне/паперове)
- `GraphicIllustrator` — графічний ілюстратор (нащадок `Artist`)
- `TechnicalWriter` — технічний письменник (нащадок `Artist`)

</details>

<details>
<summary>🌷 Пакет test</summary>

<br>

- `EmployeesTest` — клас з методом `main` для демонстрації роботи ієрархії класів

</details>
